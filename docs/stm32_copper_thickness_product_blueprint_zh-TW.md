# STM32 銅箔厚度量測儀（對標商用品）產品藍圖

> 目標：做出「可攜式、可校正、可追溯」的 PCB 銅厚量測儀，產品體驗接近市售工業量測設備。

## 1) 產品定位（你要的「類似商用產品」）

- **使用情境**：PCB 打樣廠 / 品保 / 製程工程師現場抽測。
- **量測對象**：標準 coupon（優先），再逐步擴展到工件特定測試點。
- **核心價值**：
  - 快速讀值（< 1 秒穩定）
  - 結果可追溯（含溫度、校正版本、序號）
  - 一鍵校正 + 上下限判定（OK/NG）

## 2) 功能規格（PRD v1.0）

### 2.1 量測性能（MVP）

- 厚度範圍：18–105 µm（0.5–3 oz）
- 解析度：1 µm
- 重複性（1σ）：±2 µm
- 顯示更新率：2–5 Hz
- 穩定時間：< 1 s（從接觸到穩定）

### 2.2 人機介面

- 主頁：厚度(µm)、等效 oz、溫度、狀態（OK/WARN/NG）
- 次頁：即時電阻、電流檔位、噪聲等級
- 校正頁：Zero / Gain / Slope 分步驟引導
- 設定頁：上下限、蜂鳴器、背光、語言

### 2.3 資料與追溯

- 每筆資料儲存：時間戳、厚度、溫度、R_meas、校正版本
- 匯出：USB CDC（虛擬序列埠）CSV
- 記錄容量：至少 10,000 筆（循環覆寫）

## 3) 硬體架構（量產友善）

1. **MCU**：STM32G4 / F3（高精度 ADC、DSP 指令較佳）
2. **前端類比**：
   - 可切換恆流源（1/5/10 mA）
   - 儀表放大器（低漂移）
   - 低通濾波 + 抗 ESD 保護
3. **治具**：四線式 Kelvin 探針頭（可更換探針）
4. **溫度**：板上數位溫度感測器（I2C）
5. **顯示**：2.4" SPI TFT（建議）
6. **輸入**：3 鍵 + 旋鈕（或 5-way key）
7. **通訊**：USB-C（供電 + 資料）
8. **電源**：
   - 桌上型：USB 5V
   - 攜帶型：鋰電 + 充電管理（後續版本）

## 4) 韌體架構（模組化）

- `app_measure`：採樣排程、濾波、厚度計算
- `app_calib`：Zero/Gain/Slope 校正流程
- `app_ui`：畫面狀態機、按鍵事件
- `app_storage`：參數 + 歷史資料 + CRC
- `drv_adc_dma` / `drv_lcd` / `drv_temp` / `drv_usb`
- `safety_monitor`：探針開路、超範圍、感測器異常

## 5) 製造與校正策略

### 5.1 產線校正（每台）

1. 零點校正（短路治具）
2. 增益校正（標準毫歐電阻）
3. 斜率校正（1 oz / 2 oz coupon）
4. 產生校正證書（序號綁定）

### 5.2 維護校正（使用端）

- 提供「快速日校正」模式（Zero + 單點標準片）
- 提醒週期（例如 30 天）

## 6) MVP 開發里程碑（建議）

- **M1（2 週）**：實驗板 bring-up，ADC + LCD + 基本公式
- **M2（2 週）**：四線式治具 + 溫補 + 平均濾波
- **M3（2 週）**：完整校正流程 + Flash 儲存 + USB 匯出
- **M4（2 週）**：機構整合 + 壓針一致性驗證 + 文件化

## 7) 風險與對策

- 接觸不穩定 → 探針壓力機構 + 噪聲監測 + 重測提示
- 溫漂影響 → 溫度即時補償 + 開機預熱提示
- 幾何誤差（L/W） → 固定 coupon 尺寸 + 雷雕標識 + 軟體參數鎖定

- 2.4" SPI LCD
- I2C 溫度感測器
- 四線式探針夾具 + 已知尺寸 coupon
