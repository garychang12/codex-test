# 使用 STM32 + 探針量測 PCB 銅箔厚度並顯示在 LCD：開發指南

> 先說關鍵：**直接用探針「量厚度」在工程上很困難**，建議改為「量電阻再反推厚度」。

## 1. 量測原理（建議方案）

以四線式（Kelvin）量測一段已知幾何尺寸的銅箔測試線：

- 已知：
  - 線長 `L`（m）
  - 線寬 `W`（m）
  - 銅電阻率 `ρ`（約 `1.724e-8 Ω·m`，20°C）
- 量到：
  - 電阻 `R`（Ω）

銅厚 `t` 由下式反推：

```text
t = ρ * L / (R * W)
```

再換算成 `µm` 顯示在 LCD。

## 2. 為何不能用兩線式 + 普通探針

銅箔通常是幾十微米，對應電阻很低（mΩ 等級），兩線式會被下列因素嚴重污染：

- 探針接觸電阻
- 線材與接頭電阻
- ADC 偏移與熱漂移

因此建議必用：

1. 四線式夾治具（Force+/Force-，Sense+/Sense-）
2. 恆流源 + 儀表放大器
3. 溫度補償

## 3. 系統架構

- MCU：STM32（例如 F303 / G4 / F4，具較佳 ADC 與運放資源）
- 類比前端：
  - 恆流源（如 10 mA，可切換 1/5/10 mA）
  - 儀表放大器（INA826/INA333 類）
  - RC 抗雜訊濾波
- 感測：
  - 四線式探針夾具（量測 coupon）
  - NTC 或數位溫度感測器（例如 TMP117）
- 顯示：I2C/SPI LCD（1602 I2C 或 ST7789）
- 韌體功能：
  - ADC 採樣 + 多次平均
  - 溫度補償
  - 厚度計算
  - LCD 即時顯示 + 校正頁

## 4. 設計公式與補償

### 4.1 基本厚度

```text
t_raw = ρ20 * L / (R_meas * W)
```

### 4.2 溫度補償

銅溫度係數 `α ≈ 0.0039 /°C`：

```text
R20 = R_meas / (1 + α * (T - 20))
t_comp = ρ20 * L / (R20 * W)
```

## 5. 校正流程（建議）

1. **零點校正**：短路治具取得 offset。  
2. **增益校正**：接入精密毫歐電阻（例如 10 mΩ / 50 mΩ）。  
3. **厚度比對**：用已知 1 oz / 2 oz coupon 做斜率修正。  
4. 儲存校正係數到 Flash。

## 6. STM32 韌體流程（高層）

1. 啟動：載入校正係數
2. 定時器觸發 ADC（例如 1 kHz）
3. 視窗平均（例如 128 點）
4. 計算 `V_sense` -> `R_meas = V/I`
5. 溫補後求 `t_comp`
6. LCD 顯示：厚度(µm)、等效 oz、溫度、狀態
7. 超限警報（太薄/太厚）

## 7. 驗證目標（可作為驗收）

- 量測範圍：18–105 µm（0.5–3 oz）
- 解析度：≤ 1 µm
- 重複性（1σ）：≤ ±2 µm
- 顯示更新率：2–5 Hz

## 8. 注意事項

- 被測線寬與長度誤差會直接影響厚度計算。
- 銅表面氧化、焊錫殘留、壓針力都會造成漂移。
- 若要量「成品任意位置」厚度，需改用**渦電流/超音波**專用探頭，不是簡單電阻法。

## 10. FAQ：在 STM32 上可以用 Python 嗎？

可以，但要分成兩種情境：

1. **MicroPython / CircuitPython（可行）**  
   - 需要把對應韌體燒進 STM32。  
   - 適合快速原型、UI 控制、通訊邏輯。  
   - 若你的量測前端需要高精度定時、低抖動採樣，Python 執行效能通常不如 C。  
2. **CPython（一般不行）**  
   - 標準電腦版 Python（你在 PC 上跑的那種）通常無法直接跑在 STM32 這種 MCU 上。

### 本專案建議

- **正式量測韌體**：用 STM32 HAL/C（或 C++）實作 ADC、定時與濾波。  
- **演算法驗證與校正工具**：用 Python（本 repo 的 `tools/copper_thickness_calc.py`）在 PC 端先驗證。  
- **若想加速開發**：可先用 MicroPython 做 LCD UI 與流程驗證，量測核心最終仍建議回到 C。


## 11. 完整系統架構流程（從上電到顯示）

下面用「資料流 + 控制流」方式描述一套可直接開發的版本。

### 11.1 硬體方塊圖（觀念）

1. **量測治具（四線式探針）**  
   - Force+/Force-：提供測試電流到 coupon。  
   - Sense+/Sense-：只量壓降，降低導線與接觸電阻誤差。
2. **恆流源**  
   - 提供穩定測試電流（例如 1/5/10 mA 切換）。
3. **儀表放大器 + 濾波**  
   - 放大 mV 等級感測壓降，送入 ADC 可用範圍。
4. **STM32（ADC + Timer + Flash）**  
   - 週期採樣、數位濾波、溫補、厚度計算、參數儲存。
5. **溫度感測器（NTC/TMP117）**  
   - 提供當前溫度，做銅阻溫度補償。
6. **LCD（I2C/SPI）**  
   - 顯示厚度、等效 oz、溫度、量測狀態。
7. **按鍵/旋鈕（可選）**  
   - 進入校正模式、切換頁面、設定上下限警報。

### 11.2 韌體任務切分

- **Task A：採樣任務（高優先）**  
  由 Timer 觸發 ADC（例如 1 kHz），把原始值放入 ring buffer。
- **Task B：訊號處理任務**  
  對 buffer 做平均/中值濾波，計算 `V_sense`。
- **Task C：物理量換算任務**  
  `R_meas = V_sense / I_test`，再做 `R20` 溫補與厚度換算。
- **Task D：顯示與 UI 任務**  
  每 200~500 ms 更新 LCD；處理按鍵與狀態燈。
- **Task E：校正/參數管理任務**  
  管理 zero/gain/slope 係數，寫入 Flash（含 CRC）。

### 11.3 上電初始化流程

1. `SystemInit`：時鐘、GPIO、I2C/SPI、ADC、Timer 初始化。  
2. `LoadCalibration`：從 Flash 讀校正係數與幾何參數（L/W）。  
3. `SelfCheck`：檢查 ADC 偏移、感測器連線、LCD 回應。  
4. `StartSampling`：啟用 Timer + ADC DMA。  
5. 進入主迴圈（或 RTOS scheduler）。

### 11.4 量測循環（每個更新週期）

1. 收集 N 筆 ADC（例如 128 筆）。  
2. 轉成電壓 `V_sense`（考慮 ADC 參考電壓與增益）。  
3. 依目前檔位取得 `I_test`。  
4. 求電阻 `R_meas = V_sense / I_test`。  
5. 讀取溫度 `T`，做 `R20 = R_meas / (1 + α*(T-20))`。  
6. 厚度計算 `t = ρ20 * L / (R20 * W)`。  
7. 套用校正係數（zero / gain / slope）。  
8. 檢查上下限，更新狀態（OK/WARN/ERROR）。  
9. 輸出到 LCD：`Thickness(µm)`, `oz`, `Temp`, `Status`。

### 11.5 校正模式流程

1. **Zero 校正**：短路輸入，量到 `offset_R`。  
2. **Gain 校正**：接精密標準電阻，求 `gain_k`。  
3. **Thickness Slope 校正**：用已知 1 oz / 2 oz coupon 求 `slope_k`。  
4. 存檔到 Flash（附 CRC 與版本號）。  
5. 重啟量測並顯示「Cal OK」。

### 11.6 例外處理與保護

- `Probe Open`：探針未接觸，顯示 OPEN。  
- `Overrange`：ADC 飽和或放大器超範圍。  
- `Temp Fault`：溫度感測器讀值異常。  
- `Cal Invalid`：Flash CRC 錯誤，退回預設參數。  
- `Noise High`：短時間標準差超標，提示重新壓針。

### 11.7 與 Python 的實務分工

- **STM32 端（C/HAL）**：即時採樣、濾波、補償、顯示。  
- **PC 端（Python）**：
  - 使用 `tools/copper_thickness_calc.py` 驗證公式。  
  - 做校正資料回歸（例如 slope/offset 擬合）。  
  - 產生可燒錄到 STM32 的校正參數檔。
